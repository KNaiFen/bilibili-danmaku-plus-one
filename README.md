# Bilibili 直播弹幕 +1 复读按钮

用于哔哩哔哩直播间的 Tampermonkey（油猴）用户脚本。在播放器中右键选中弹幕后，点击一级菜单中的「+1 弹幕复读」，即可使用当前登录账号发送同一条弹幕。

## 文件

- `bilibili-danmaku-plus-one.user.js`：可直接安装的单文件脚本，原样导入提供的 v1.1.6 源码。
- `.gitignore`：排除本地配置、日志和生成物。

## 安装和使用

依赖支持用户脚本的浏览器和 Tampermonkey 扩展；无需构建或安装 npm 依赖。

1. 在 Tampermonkey 管理面板中新建脚本，用 `bilibili-danmaku-plus-one.user.js` 的完整内容替换默认模板并保存；也可以通过扩展的文件导入功能安装该文件。
2. 启用脚本，登录哔哩哔哩并打开或刷新 `https://live.bilibili.com/` 下的直播间。
3. 右键点击播放器中正在显示的弹幕，在弹出的一级菜单中选择「+1 弹幕复读」。
4. 发送成功后默认显示「弹幕+1成功」。可在 Tampermonkey 的脚本菜单中切换成功提示，设置会保存在本地；切换后刷新页面可更新菜单文字。

输入来自选中的弹幕和当前直播间地址；输出是向该直播间发送一条同内容弹幕。发送错误会记录在浏览器开发者工具的控制台中，日志前缀为 `[Danmaku +1]`。

## 实现与限制

- 脚本只匹配 `https://live.bilibili.com/*`，通过监听页面变化向播放器原生右键菜单插入选项，并设有 350 毫秒的连续点击间隔。
- 发送时读取当前登录会话中的 `bili_jct` Cookie，携带登录凭据请求 Bilibili 的弹幕接口；无需在文件中填写账号或 Cookie。
- 房间 ID 从 URL 数字路径读取。短房间号、播放器菜单结构或接口签名规则发生变化时，可能需要适配；当前源码优先读取本地 WBI 参数，并包含固定的后备参数。
- 成功提示开关优先使用油猴存储，缺少对应接口时回退到页面 `localStorage`。
- 保留原脚本的 MIT 许可标记及 Greasy Fork 下载、更新地址。扩展可能从该地址更新已安装脚本；维护本地修改版时，应相应调整脚本的更新设置。

## 本地检查

在本项目目录中使用 Node.js 检查语法：

```bash
node --check bilibili-danmaku-plus-one.user.js
```

语法检查不会打开直播间或发送弹幕。实际菜单兼容性和发送结果需要在登录后的直播间中验证。

`generated/`、`cache/`、`out/` 和日志文件仅用于本地调试，不提交到 Git。不要将 Cookie、账号信息或真实配置加入仓库。
