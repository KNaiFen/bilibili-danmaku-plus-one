# Bilibili 直播弹幕 +1 复读按钮

用于哔哩哔哩直播间的 Tampermonkey（油猴）用户脚本。在播放器中右键选中弹幕后，点击一级菜单中的「+1 弹幕复读」，即可使用当前登录账号发送同一条弹幕。

鼠标悬停在普通弹幕上时，滚动弹幕停在当前位置，顶部或底部固定弹幕保持显示；移开后继续滚动或按剩余时间消失。只暂停命中的一条弹幕，鼠标不动时经过鼠标的弹幕也会停住。

悬停时显示圆角、半透明灰黑色操作浮窗，包含「回复」「复制」「复读+1」三个按钮。「回复」为置灰占位；「复制」复制原始弹幕文字并显示「已复制」；「复读+1」使用当前账号发送同内容弹幕。鼠标移入浮窗时继续暂停，离开弹幕和浮窗后恢复。

浮窗默认在弹幕下方，底部空间不足时放到上方，左右位置限制在播放器可见范围内，支持窗口缩放和全屏。浮窗与弹幕之间保留可移动的空隙，并提供 180 毫秒离开缓冲，便于斜向移入按钮。

右键打开该条弹幕的菜单后，操作菜单期间继续保持暂停。菜单关闭后，鼠标仍在弹幕上则继续停留，否则恢复正常。

## 文件

- `bilibili-danmaku-plus-one.user.js`：可直接安装的 v1.3.0 单文件脚本，基于提供的 v1.1.6 修改。
- `tests/`：用保存的真实弹幕引擎运行浏览器回归检查。
- `.gitignore`：排除本地配置、日志和生成物。

## 安装和使用

依赖支持用户脚本的浏览器和 Tampermonkey 扩展；无需构建或安装 npm 依赖。

1. 在 Tampermonkey 管理面板中新建脚本，用 `bilibili-danmaku-plus-one.user.js` 的完整内容替换默认模板并保存；也可以通过扩展的文件导入功能安装该文件。
2. 启用或更新脚本后，登录哔哩哔哩并刷新 `https://live.bilibili.com/` 下的直播间。新版在 `document-start` 接入弹幕引擎，安装后需要刷新才能完整生效。
3. 鼠标移到播放器中的弹幕上，在浮窗中点击「复制」或「复读+1」。也可右键点击弹幕，在一级菜单中选择「+1 弹幕复读」。
4. 发送成功后默认显示「弹幕+1成功」。可在 Tampermonkey 的脚本菜单中切换成功提示，设置会保存在本地；切换后刷新页面可更新菜单文字。

输入来自选中的弹幕和当前直播间地址；输出是向该直播间发送一条同内容弹幕。发送错误会记录在浏览器开发者工具的控制台中，日志前缀为 `[Danmaku +1]`。

## 实现与限制

- 脚本只匹配 `https://live.bilibili.com/*`，通过监听页面变化向播放器原生右键菜单插入选项，并设有 350 毫秒的连续点击间隔。
- 复读内容只取当前菜单中带 `data-auto-remove="1"` 的选中弹幕项；没有选中弹幕时移除按钮，不再从普通菜单或历史弹幕猜测文字。关闭菜单前读取当前文字，避免菜单销毁后丢失内容。
- 悬停功能通过 `unsafeWindow` 访问页面的 `LiveDanmakuEngine`，调用单条弹幕的暂停/恢复方法，并在悬停期间阻止该条弹幕按寿命回收；移开时按引擎时间补偿，避免视频暂停期间多加显示时长。
- 浮窗读取引擎中的原始弹幕文字，复制优先使用 `GM_setClipboard`，缺少油猴剪贴板接口时回退到浏览器 Clipboard API。更新脚本时油猴可能提示新增剪贴板权限。
- 浮窗与右键菜单共用复读发送和 350 毫秒防连点逻辑。操作浮窗不会触发播放器的点击行为；打开右键菜单时隐藏浮窗，关闭后按当前鼠标位置恢复。
- 支持普通滚动、反向滚动、顶部固定和底部固定弹幕（模式 1/6/5/4），不处理礼物特效或高级弹幕。弹幕停在原位置，不跟随鼠标拖动。右键菜单打开期间保持暂停；菜单关闭且鼠标移出弹幕、窗口失焦或页面隐藏时解除暂停。
- 当前引擎适配依据本地保存的 Room Player 3.11.8 / danmaku-x 1.1.20。播放器更新内部接口后可能需要重新适配；缺少引擎接口时复读菜单仍可独立工作。
- 发送时读取当前登录会话中的 `bili_jct` Cookie，携带登录凭据请求 Bilibili 的弹幕接口；无需在文件中填写账号或 Cookie。
- 房间 ID 从 URL 数字路径读取。短房间号、播放器菜单结构或接口签名规则发生变化时，可能需要适配；当前源码优先读取本地 WBI 参数，并包含固定的后备参数。
- 成功提示开关优先使用油猴存储，缺少对应接口时回退到页面 `localStorage`。
- 保留原脚本的 MIT 许可标记及 Greasy Fork 下载、更新地址。扩展可能从该地址更新已安装脚本；维护本地修改版时，应相应调整脚本的更新设置。

## 本地检查

在本项目目录中使用 Node.js 检查语法：

```bash
node --check bilibili-danmaku-plus-one.user.js
```

浏览器回归检查需要 Node.js/npm、Chrome，以及 `.example/*_files/danmaku-v2.js*` 中保存的弹幕引擎。用 Git Bash 运行：

```bash
bash tests/run-browser-check.sh
```

测试默认通过 `npx` 调用 Playwright CLI；也可用 `PWCLI` 指定已有的 CLI shell 包装脚本。检查包括滚动暂停/恢复、固定弹幕超时保护、静止鼠标命中、视频暂停、失焦释放、节点复用、右键菜单锁定、浮窗复制/复读、按钮状态、边缘避让、窄窗口、缩放和全屏。测试会拦截网络并模拟剪贴板及发送接口，不向直播间发送消息。真实登录、油猴沙箱、系统剪贴板和 B 站发送接口仍需在线验证。

`.example/` 保存本地网页样本；测试从中复制引擎至 `generated/`，截图输出到 `output/playwright/`。这些目录、`.playwright-cli/`、`cache/`、`out/` 和日志不提交到 Git。不要将 Cookie、账号信息或真实配置加入仓库。
