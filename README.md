# Bilibili 直播弹幕一键复读 +1 浮窗

一个用于哔哩哔哩直播间的油猴脚本。鼠标放到弹幕上，就能让它停下来，再通过弹出的浮窗回复、复制或一键复读。

## 功能

- **悬停暂停**：鼠标放到弹幕上时，滚动弹幕停止移动，顶部或底部固定弹幕也不会到时消失。移开后恢复正常，操作浮窗或右键菜单时仍会保持暂停。
- **快捷浮窗**：提供「回复」「复制」「复读+1」三个按钮。浮窗采用紧凑的半透明样式，会自动避让播放器边缘，也支持全屏使用。
- **回复与复制**：点击「回复」即可像 B 站的「@TA」一样选中发送者，再输入并发送回复内容；点击「复制」可复制这条弹幕的文字。不支持回复时，回复按钮会变灰。
- **一键复读**：点击「复读+1」发送相同内容的弹幕，也可以在右键菜单中展开对应弹幕，在「复制弹幕」下方选择「+1 弹幕复读」。多条弹幕重叠时，每条弹幕的菜单都可以单独复读。
- **提示开关**：可通过油猴的脚本菜单关闭或开启复读成功提示。

## 安装

1. 在浏览器中安装 Tampermonkey（油猴）扩展。
2. [安装脚本](https://raw.githubusercontent.com/KNaiFen/bilibili-danmaku-plus-one/main/bilibili-danmaku-plus-one.user.js)，或在油猴中新建脚本，填入仓库中 `bilibili-danmaku-plus-one.user.js` 的完整内容并保存。
3. 启用脚本，登录 B 站并刷新直播间。
4. 悬停弹幕使用浮窗，或右键展开对应弹幕的二级菜单。
